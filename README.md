# Global Acqua - Sensory Analysis System

A lightweight, client-side sensory quality control web application for water quality testing.

## Features

- **Regular Sensory Tests** — Appearance, Odour & Taste evaluation
- **Blind Tests** — Anonymous sample evaluation with color codes
- **Proficiency Tests** — Panelist skill assessment
- **Session Management** — Create sessions with unique codes, share with panelists
- **Admin Dashboard** — User management, session monitoring, date-filtered views
- **Reports** — Detailed evaluation reports with print support
- **Data Persistence** — All data stored in browser localStorage

## Tech Stack

- Pure HTML/CSS/JavaScript (no framework, no build step)
- Google Fonts (Space Grotesk + Inter)
- localStorage for data persistence
- Fully responsive design

## Usage

1. Open the application in your browser
2. Login with admin or panelist credentials
3. Create or join a sensory evaluation session
4. Complete ballot forms for water quality testing
5. View reports and export as PDF
